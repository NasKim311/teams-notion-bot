# 알려진 한계와 개선 후보

2026-10-08 프로젝트 분석에서 나온 항목이다. 해결하면 이 목록에서 지우고, 결정이 필요했던 것은 [decisions.md](decisions.md)에 남긴다.

## 보안·운영
- **비밀번호 시도 횟수 제한 없음**: 공유 비밀번호 하나라 무차별 대입에 약하다.
  - 후보: Cloudflare 속도 제한 규칙(`/api/*`), 또는 Cloudflare Access로 회사 이메일 인증을 앞에 두기.
- **로컬과 운영이 같은 Notion DB를 씀**: 로컬 개발·확인 중에 만든 페이지가 실제 DB에 섞인다.
  - 후보: 테스트용 DB를 따로 만들고 `.dev.vars`의 NOTION_DATABASE_ID만 바꾸기.
- **원격 저장소 백업**: GitHub(`origin`)에 push되어 있는지 주기적으로 확인한다.

## 코드 품질
- **입력 화면 JS에 자동 테스트 없음**: `src/page/client.js`(카드 렌더링, 이미지 유지, 순차 등록, 기존 이슈 선택)는 수동 확인에만 의존한다. 린트(Biome)는 적용된다.
  - 후보: 렌더링한 HTML의 구조 테스트, 또는 브라우저 E2E(Playwright 등, devDependency).
- **Notion API 버전**: `2022-06-28`로 동작한다. 최신 API의 data source 구조로 옮길 필요가 생기면 `src/notion/client.ts`와 `scripts/lib/notion.ts`를 함께 바꾼다.

## 기능 한계 (규칙 기반이라 생기는 것)
- **긴 제목**: 문장이 길고 끊을 절이 없으면 제목이 60자를 넘는다 (100자까지 허용). 미리보기 카드에서 고친다.
- **처음 보는 양식**: 모르는 라벨은 "참고" 섹션으로, 라벨 없는 글은 "현상"으로 간다.
- **답글의 라벨 없는 내용은 본문에서 빠짐**: 중요한 답글은 미리보기 본문에 `처리 상황 :` 같은 라벨을 붙여야 남는다.
- **Teams 원문 링크를 저장하지 않음**: 사용자 결정이다. 원문 대화로 돌아갈 방법이 없다.
- **기존 이슈 찾기는 레드마인 링크 일치만**: 일감 번호가 없는 이슈는 업데이트 대상으로 찾지 못한다.
