# 배포 기록

운영(https://teams-notion-bot.by-nas.workers.dev)에 배포한 버전 목록이다. 최신이 위에 있다.

- `npm run deploy`가 배포할 때마다 자동으로 한 건씩 추가하고 커밋한다. **직접 고치지 않는다.**
- 배포마다 같은 이름이 세 곳에 남는다.
  - git 태그 `deploy-날짜.순번`: 배포한 커밋을 가리킨다.
  - Cloudflare 버전의 태그와 메시지(`커밋 제목`): `npx wrangler deployments list`로 확인한다.
  - 이 문서: 아래 항목.
- 바뀐 것: 이전 배포 이후의 `feat`/`fix` 커밋 제목이다. 문서·구조 정리(`docs`/`refactor` 등)는 적지 않는다.
- 문제가 생기면 이전 배포의 Version ID로 되돌린다: `npx wrangler rollback <Version ID>`. 되돌린 사실은 이 문서에 직접 한 줄 남긴다 (자동 기록 안 됨).
- 시크릿을 바꿔도(`wrangler secret put`) Cloudflare에 새 버전이 생기지만 코드는 그대로라 여기에는 적지 않는다.
- 처음 5건(deploy-2026-10-07.1 ~ deploy-2026-10-08.3)은 이 기록을 만들기 전 배포라 나중에 채웠다. 커밋은 배포 시각 바로 전 커밋으로 추정했다.
